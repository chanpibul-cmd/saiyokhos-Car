ตารางคิวการใช้รถ

ตรวจสอบตารางเวลา คิวรถที่ได้รับการจัดสรร และสถานะภารกิจทั้งหมด

จัดการจัดรถยนต์และคนขับ

กำหนดพนักงานขับรถและทะเบียนรถสำหรับรายการคำขอที่ส่งเข้ามา

รายการคำขอจัดรถ

จัดการ ID ออกเดินทาง กลับถึง ผู้ขอ เรื่อง สถานที่ ประเภท

รายงานบันทึกการขับรถ (พขร.)

สำหรับพนักงานขับรถบันทึกเวลาปฏิบัติงานจริง เลขไมล์กิโลเมตร และค่าน้ำมัน

ภารกิจที่ได้รับมอบหมาย

จัดการ ID ขอวันที่ ถึงวันที่ ผู้ขอ สถานที่ ผู้ขับรถ ทะเบียน

ประวัติการใช้รถและพิมพ์เอกสาร

ค้นหาประวัติย้อนหลัง ตรวจสอบรายละเอียด และสั่งพิมพ์เอกสารขอใช้รถมาตรฐาน A4

ประวัติการใช้รถทั้งหมด

ดูข้อมูล ID สถานะ ขอวันที่ ถึงวันที่ ผู้ขอ สถานที่ คนขับ ทะเบียน ระยะทาง
